## 6. 기기에 저장하는 정보와 자동 수집

로그인 유지를 위해 웹 브라우저의 로컬 저장소 또는 Android 앱의 저장 공간에 인증 세션 정보를 보관합니다. 브라우저·플랫폼에 따라 저장 방식이 달라질 수 있습니다. 서비스 자체 로그인은 이 저장 정보와 인증 토큰을 사용합니다.

계정 화면에서 로그아웃하면 현재 기기의 세션을 종료합니다. 브라우저의 사이트 데이터 삭제나 앱의 데이터 삭제로 기기에 저장된 정보를 지울 수 있으나, 서버의 계정·학습 기록까지 삭제되는 것은 아닙니다. 저장을 차단하면 로그인 유지가 제한될 수 있습니다.

`[확정 필요: 호스팅·인증·연동 사업자의 실제 쿠키/자동 수집 기술, 목적·보관기간·거부 설정 안내]`

현재 코드에는 실제 AdMob 광고, 광고 식별자 수집, FCM 푸시 및 별도 분석 SDK 연동이 구현되어 있지 않습니다. 광고나 알림을 도입하면 실제 수집·전송 항목과 필요한 설정·동의 절차를 반영하여 방침을 갱신합니다. 호스팅·인증 로그까지 수집하지 않는다는 의미는 아닙니다.

## 9. 이용자와 법정대리인의 권리

이용자는 관련 법령에 따라 자신의 개인정보에 대한 열람·정정·삭제·처리정지와 동의 철회를 요청할 수 있습니다. 제1항의 연락처로 요청하면 필요한 최소 범위에서 본인 또는 정당한 대리인인지 확인하여 처리합니다. 법령에 따른 제한 사유가 있는 경우 그 사유와 처리 결과를 안내합니다.

- 앱 안에서 계정 삭제 요청: 나 → 계정 및 데이터 삭제 → 본인 확인 → 최종 삭제 확인.
- 앱을 설치하지 않고 삭제 요청: `[배포 확인 후 확정: 서비스 도메인/account/delete/]`. 가입 이메일로 확인 링크를 받아 요청한 브라우저에서 열면 삭제 절차를 계속할 수 있습니다. 이메일 확인만으로 계정을 삭제하지 않습니다.
- 삭제 대상·처리 시점·예외 보관: `[확정 필요: 제3·8항과 일치하는 안내]`
- 로그아웃은 현재 기기의 로그인 종료이며 회원 탈퇴가 아닙니다.
