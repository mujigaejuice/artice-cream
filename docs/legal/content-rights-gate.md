## 데이터와 적용 범위

- `content_source_rights`: 소스 상태(`unreviewed`, `permitted`, `restricted`, `blocked`), 공개 근거 URL, 확인일, 만료일, `allow_collect`·`allow_process`·`allow_publish`. 내부 검토 메모는 클라이언트가 읽지 못한다.
- `articles.rights_*`: 개별 글 상태·근거·확인일·만료일·필수 표시·내부 검토 메모. 기존 1,538건은 기본값 `unreviewed`로 보존한다. 적용 전 ready 82편과 가공본 246개도 공개에서 제외한다. 실제 기사·개인 기록을 삭제하는 작업은 아니다.
- 서버 코드 배포 후 최종 스냅샷은 ready 86편·가공본 258개이며 공개 가능 글은 0편이다. DB 적용과 서버 배포 사이에 늘어난 가공본도 미확인으로 차단했다. DB 목록은 현재 40개와 과거 `woowahan`까지 41개를 포함한다.
- `rights_attribution`: `author`, `originalTitle`, `licenseLabel`, `licenseUrl`, `changes`, `notices`. 마지막 항목은 원문에 제공된 권리·면책·기존 변경 고지를 보존하고, 없으면 빈 문자열을 기록한다. 허락을 임의로 만들어 넣지 않는다.
- `domain_terms.origin_article_ids`: 파생 용어 목록의 근거 기사. 기존 목록은 근거가 없으므로 숨기며, 앞으로는 공개 가능한 가공본만 집계한다.

소스와 글 양쪽이 `permitted`이고, 행위별 허용 플래그와 근거·확인일·유효기간·필수 표시가 모두 맞아야 처리한다. `publish`는 `ready`, `process`는 `pending`을 추가로 요구한다. 알 수 없는 소스, 누락된 테이블, DB 오류, 만료·철회는 차단한다.

## 수집·가공·표시

수집 크론은 수집 승인이 있는 소스만 연다. 새 글은 메타데이터만 미확인 상태로 기록하고, 가공 승인 소스와 개별 승인 글만 분류 LLM에 전달한다. 가공 승인이 없다면 분류·대기열 만료를 실행하지 않는다. 가공만 승인된 소스는 피드를 다시 열지 않고 기존 승인 글을 분류한다. 분야가 이미 지정된 승인 글은 분야별 가공 크론이 처리한다.

가공은 본문 요청 전과 생성 결과 저장 전에 최신 권리를 다시 확인한다. 발행처 이미지 사용은 텍스트 권리에 포함시키지 않으며, 새 가공에서는 이미지 URL과 원문 전문을 저장하지 않는다. 이미 저장된 원문은 이번에 삭제하지 않았고, 보관/파기 정책에 따라 별도 정리해야 한다.

오늘 카드·미저장 결과 카드·콘·월 목록, 직접 읽기·퀴즈·채점·저장 API에서 권리를 검사한다. 미허용 읽기는 쿼터를 소비하지 않고, 채점/저장 요청도 개인 기록을 변경하지 않는다. 리더에 원제·저자·라이선스·변경·기존 고지를 표시한다.

DB의 restrictive RLS가 기사·가공본·퀴즈·진행 기록·파생 용어의 직접 조회를 제한한다. 정답은 허용 콘텐츠라도 기존 정책에 따라 직접 조회되지 않는다. 서비스 역할은 RLS를 우회하므로 API에서도 별도 검사한다. 원문 전문과 내부 검토 메모의 컬럼 권한을 제한했다.

API 응답과 브라우저 요청은 `no-store`다. 탭 복귀와 브라우저 뒤로가기 복원 시 화면 데이터를 다시 조회한다. 이미 다운로드된 사본·스크린샷·계속 열린 화면을 원격으로 회수하는 기능은 아니다. 실기기·브라우저 조작 검증은 별도다.

## 검토 후 승인과 철회

1. [소스별 기록](source-rights-register.md)에 따라 이용 조건·정확한 라이선스·저자·제3자 자료 예외·원문 보관·실제 외부 제공사 조건을 확인한다. 번역/재작성, 용어/퀴즈, 웹/앱 제공, 광고 이용을 각각 검토한다.
2. 소스의 공개 근거와 확인일·만료일을 기록하고, 허용된 행위의 플래그만 켠다. 소스 상태만 변경하고 글을 일괄 승인하지 않는다.
3. 개별 URL과 원문 표본을 확인하고 필수 표시를 모두 기록한 뒤 해당 글의 `rights_status`를 `permitted`로 바꾼다. 가공 결과 표본도 검토한다.
4. 철회/신고 조사 시 해당 소스 또는 글의 `rights_status`를 `blocked`로 변경한다. 소스 차단은 그 소스의 기존 저장본·퀴즈·파생 목록에도 적용된다. 개인 점수와 저장 기록은 내부 보존하되 공개 화면에 가공 내용을 노출하지 않는다.
5. 권한 없는 보관이 확인되면 원문·가공본·업체 사본의 삭제와 문의 회신을 별도 수행한다. 연락처·담당자·신고 접수 창구는 아직 미확정이다.
