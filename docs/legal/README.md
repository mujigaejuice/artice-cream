## 먼저 해결할 순서

1. **콘텐츠 승인과 재개**: 미확인 콘텐츠의 공개를 제한했다. Kubernetes·Daniel Lemire 등 공개 라이선스 후보의 개별 글·저자·예외·표시와 실제 제공사 조건을 확인하고 승인된 범위만 재개한다. AWS·Databricks·Cloudflare는 별도 허락/예외, InfoQ는 현재 장문 재작성 범위를 추가 확인한다.
2. **운영 정보 확정**: 운영자 공개명, 개인정보 보호책임자·연락처, 대상 연령, LLM 게이트웨이 실제 업체와 계약을 채운다. Supabase·Vercel·인증 메일 발송 업체의 처리 국가·보관기간·재위탁도 확인한다.
3. **삭제 실기기 확인·보관 정책 확정**: 계정 삭제 운영 API·DB·세션 검사까지 완료했다. 실기기 검증이 가능할 때 이메일 앱 왕복을 확인하고, 기간별 파기·제공사 로그/백업 처리 절차를 확정한다.
4. **방침 공개와 제출 정보 일치 확인**: 미확정 표시를 모두 해소하고 실제 구현과 대조한 뒤 로그인 없이 열리는 HTML 개인정보처리방침 URL을 제공한다. 앱 내부 링크와 Play 데이터 보안·계정 삭제 양식을 같이 검증한다.

Google Play는 광고 유무와 별개로 개인정보처리방침 공개를 요구하며, 앱에서 계정을 만들 수 있으면 앱 안팎에서 삭제를 요청할 수 있어야 한다. [사용자 데이터 정책](https://support.google.com/googleplay/android-developer/answer/10144311?hl=ko), [계정 삭제 요구사항](https://support.google.com/googleplay/android-developer/answer/13327111?hl=ko).
