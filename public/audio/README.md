## 상점 배경음악

2026-10-27에 작업 폴더 루트에서 받은 MP3 네 파일을 이름만 URL에 맞게 바꿔 `public/audio/`에 옮겼다. 상점에서는 15초를 미리 듣고, 구매한 곡을 선택하면 전역 배경음악이 해당 파일로 바뀐다. 선택을 해제하면 기존 무료 기본곡 `ice-cream-basic.mp3`로 돌아간다.

| 상품 키 | 파일 |
|---|---|
| `one-scoop-of-joy` | `one-scoop-of-joy.mp3` |
| `tiptoe-into-sunlight` | `tiptoe-into-sunlight.mp3` |

## 이전 오리지널 음원 제작 기록

사용자 요청으로 2026-10-23에 만든 30초 오리지널 배경음악.

- 파일: `ice-cream-stroll-30s.wav`
- 분위기: 작은 아이스크림 가게, 발랄하고 귀여운 일상, 편안하고 사랑스러운 느낌
- 구성: 마림바 멜로디, 우쿨렐레를 연상시키는 합성 현악 반주, 둥근 베이스, 잔잔한 패드, 작은 벨과 셰이커
- 96 BPM, 4/4박자, 12마디, 정확히 30초
- 44.1 kHz / 16-bit / 스테레오 PCM WAV, 약 5.29 MB
- 최대 샘플 피크 약 -4.01 dBFS, RMS 약 -19.10 dBFS (LUFS 측정값 아님)

일상 시뮬레이션 게임의 아늑한 분위기를 참고 방향으로 삼고, 멜로디와 반주는 새로 구성했다. 기존 게임 음원이나 외부 샘플을 사용하지 않았다. 악기 소리는 코드로 합성했으며 실제 악기 녹음이 아니다.

음표의 잔향과 룸 반사를 시작 부분으로 순환시켜 반복용으로 렌더링했다. WAV를 반복 재생할 때 곡 자체의 끝에 별도 무음이나 페이드아웃이 없다. 실제 재생기의 반복 기능에 따라 연결감은 달라질 수 있다.

제작 당시 재생 경로는 `/audio/ice-cream-stroll-30s.wav`였다. 현재 플레이어의 기본곡은 `ice-cream-basic.mp3`다. `components/BackgroundMusic.tsx`는 루트 레이아웃에 연결되어 20% 볼륨으로 반복 재생하며, 웹/앱에서 ON/OFF를 저장하고 화면 이동 중 재생을 유지한다. 탭 숨김·앱 백그라운드에서는 일시정지한다.

생성 원본은 `scripts/generate-bgm.mjs`이며 Node.js로 실행하면 음원과 측정 JSON을 재생성한다. 외부 패키지나 네트워크는 사용하지 않는다.

파일 길이, PCM 형식과 생성 시 피크 수치를 검증했다. 실제 스피커·이어폰을 통한 청취 검증은 수행하지 않았다.
